# Mithilish Ad Agency: Landing Page

Responsive marketing landing page for a (fictional) ad agency, in plain HTML and CSS.

**Live:** https://grapherithilesh27.github.io/mithilish-landing-page-/

- Gradient hero with headline and two calls to action
- Service cards with hover effects
- About section with stats
- Call-to-action banner and contact footer
- Mobile-friendly layout (CSS grid, `clamp()` typography, breakpoints at 720px and 420px)

Open `index.html` in a browser to view it locally.
